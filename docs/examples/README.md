# Example output

Generated by running the real pipeline over six papers from the developer's own Zotero
library (see `tests/fixtures/goldset-manifest.json`).

Only the **metadata-derived** artifacts are committed here — they contain no quoted text
from the papers:

| File | Produced by |
|---|---|
| `synthesis-index.md` | `review.py --generate` |
| `synthesis-methods-matrix.md` | `review.py --generate` |
| `refs.bib` | `review.py --generate` |

The judgement artifacts — `themes.md`, `gaps.md`, `contradictions.md`, `review-draft.md` —
were also produced and pass `review.py --check`, but they quote from third-party papers and
so are not committed to a public repository. They live in the working corpus.

`docs/m4-qa-examples.md` shows worked question answering over the same six papers, including
a question the corpus cannot answer and the system declining it.
